# Banking & Financial Stress Analysis (Malaysia)

Credit anomaly detection across commercial and Islamic banking portfolios, financial stability indicators (household debt service ratio, gross impaired loans ratio), and Malaysian Government Securities (MGS) vs corporate bond credit spread curves (Tables 4.3, 4.4, 4.6).

## Installation & Running

```bash
pip install -r requirements.txt
pytest -v
streamlit run app.py
```
